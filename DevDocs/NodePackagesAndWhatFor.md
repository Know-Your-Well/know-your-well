🌐 Server & Backend Frameworks

• express: This is your core web server framework used to host APIs, serve static files, and handle HTTP requests.
• body-parser: Middleware for Express to handle incoming request bodies.
• cors: Middleware for Express to enable Cross-Origin Resource Sharing.
• express-session: Middleware for Express to manage user sessions.

🗄️ Database & Authentication (Backend)

• mssql: Microsoft SQL Server client for Node.js (connects your server to a database).
• samlify & @authenio/samlify-node-xmllint: SAML 2.0 authentication library for Node.js servers.

💻 Client-Side / Front-End (React)

These run in the user's browser, not on your backend server:
• bootstrap, reactstrap, semantic-ui-react: UI and styling component libraries.
• axios: HTTP client used by the browser to fetch data from your Express server.
• web-vitals: Metrics tool for tracking front-end performance.

🛠️ Development & Build Tools

These are only used during development and testing, not to serve the app in production:
• nodemon: Automatically restarts your Express server when you make code changes.
• concurrently: Runs multiple commands (like starting your backend and frontend at the same time).
• dotenv: Loads environment variables from a .env file.
• @babel/...: Compiles modern JavaScript/React code into browser-compatible code.
• jest...: Testing framework tools.
• prettier: Code formatter.
